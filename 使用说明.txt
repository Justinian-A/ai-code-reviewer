========================================
  AI 代码评审助手 - 使用说明
========================================

一、快速开始（推荐）

  双击运行「启动器.py」即可自动启动

  前提条件：
  - 已安装 Python 3.8+
  - 已安装 Node.js 16+
  - 已安装 Git

  首次运行会自动安装依赖，需要联网

========================================

二、手动启动

  1. 安装后端依赖
     cd backend
     pip install -r requirements.txt

  2. 构建前端
     cd frontend
     npm install
     npm run build

  3. 启动服务
     cd backend
     python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

  4. 访问
     打开浏览器访问 http://localhost:8000

========================================

三、打包成安装包

  双击运行 build-desktop.bat

  前提条件：
  - 已安装 Node.js
  - 已安装 Python
  - 已安装 npm (随 Node.js 一起安装)

  打包完成后，安装包在 electron/dist 目录下

========================================

四、使用方法

  1. 启动后访问 http://localhost:8000
  2. 输入 GitHub PR 链接
  3. 填入 GitHub Token（推荐）
  4. 点击「开始分析」
  5. 等待 AI 分析完成
  6. 查看分析报告

========================================

五、获取 GitHub Token

  1. 访问 https://github.com/settings/tokens
  2. 点击「Generate new token」
  3. 选择权限：repo（全部）
  4. 生成并复制 Token

========================================

六、常见问题

  Q: 启动失败怎么办？
  A: 检查 Python 和 Node.js 是否正确安装

  Q: 分析失败怎么办？
  A: 检查 GitHub Token 是否正确，网络是否正常

  Q: 如何停止服务？
  A: 在命令行窗口按 Ctrl+C
